## Ce qui est fait

1. **Route `GET /config`** (`internal/exporter/config.go`, 24 lignes). Elle est déclarée dans le bloc `if cfg.serveRemote` de `newMetricsHandler`, donc derrière la même authentification BasicAuth ou mTLS que les autres routes.
   - `resolveInstance` / `instanceNames` : `?instance=` est obligatoire sur un daemon multi-instance (400 sinon, 404 pour un nom inconnu).
   - Elle rend `FetchConfig` via `encodeJSON`. J'ai d'abord vérifié sur un vrai Caddy les octets de `/config/` : JSON compact, `<&>` échappés en `\u003c\u0026\u003e`, et un `\n` final. `json.Encoder` sur un `RawMessage` compacte et échappe, deux opérations idempotentes sur ce format, puis ajoute `\n`. Le résultat est donc identique octet pour octet (confirmé par l'essai). Un `w.Write(raw)` aurait perdu le `\n`.
   - **Si Caddy ne répond pas : 502 Bad Gateway**, avec la raison dans le corps. Pourquoi 502 :
     - le daemon fonctionne ; il n'est ici que la passerelle vers l'API d'admin, et c'est ce qu'il y a derrière qui a échoué ;
     - 503 veut déjà dire « pas encore de snapshot » sur `/snapshot`, c'est-à-dire un état du daemon ;
     - 500 désignerait le daemon comme fautif ;
     - un code < 500 deviendrait un `RefusedError` côté client, et un « remote request refused » dans `traceRemote`. Or une panne de Caddy n'est ni un refus ni définitive : `r` relance la lecture.
   - `traceRemote` surveille `/config` (401 tracé, vérifié par test et par l'essai).
2. **Une seule table** : j'ai ajouté `FetchConfig` à l'interface `exporter.CertSource`. `*HTTPFetcher` la satisfait déjà, donc `cfg.certSources` sert `/certificates` et `/config` sans code en plus. J'ai gardé le nom, voir Q1.
3. **`RemoteFetcher.FetchConfig`** passe par `do`. Il implémente `configFetcher`, et l'UI n'a pas d'autre changement que les gardes retirées.
4. **UI** : les deux gardes `if a.config.Remote != "" { return nil }` et l'entrée `tabConfig` de `remoteUnavailable` sont retirées, rien d'autre. La map garde son unique entrée, et la condition de la ligne 396 n'a pas bougé.
5. **Doc** :
   - `docs/remote.md` : liste des routes, paragraphe TUI, et un paragraphe Security sur la config entière et ses secrets (jetons DNS ACME, empreintes `basic_auth`, en-têtes vers les upstreams), « as `ember` run over SSH on the server shows it » ;
   - CHANGELOG, Unreleased / Added ;
   - `docs/cli-reference.md:465` : c'est un écart, voir plus bas.

**Code d'Alexandre** : non modifié. `git blame` sur `feat/remote-minimal` montre que toutes les lignes touchées viennent de `1378f47`, `f53cb04` ou `374dae3` (david.merle). L'ajout dans `newMetricsHandler` tombe dans le bloc `if cfg.serveRemote` de `1378f47`.
